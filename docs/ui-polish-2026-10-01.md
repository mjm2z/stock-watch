The production build, type checking and lint pass locally (existing lint warnings
remain). The current JavaScript suite has 107 passing tests; the worker suite has
410 passing tests. Cases include byte/count cache limits and expiry, time-window
limits/coarsening, duplicate-bar merging, history extension while retaining bars,
request cancellation, exhausted-history suppression, shared background reads and
main-thread timer responsiveness.

for scan-specific reason filtering, with no temporary sort in that query plan.
HTTP measurements on the local Mac: first filtered Signals response about 67ms,
cached response 17ms, health response 12ms. These are fixture observations, not
production latency guarantees or measurements of a1347-m's disk contention.

Browser checks use isolated databases and mocked history/feed/market responses;
they do not establish live provider coverage or broker connectivity. Desktop (1440px) and mobile (390px), dark/light browser checks passed: exact
badge/chart edge alignment, 16px header gap, 30px/26px price, no horizontal overflow
or JavaScript errors, and additional history requests after mouse-wheel expansion.
Checks used the production build and a complete isolated schema; an earlier harness
run used incomplete mock API response shapes and was corrected before passing.

All 51 deployment-helper tests pass locally. Feed tests pass with isolated localhost
ports. Linux staging remains required before the release is installable.

## Deployment and rollback

First complete storage maintenance outside US trading hours and verify its installed
receipt, integrity/compaction result and services. Then install the reviewed UI
stage through its own installer. It verifies a fresh recovery copy before migration
024 and retains runtime/config/artifact recovery data. Do not run competing installers.
Rollback must use compatible code/database pairs and preserve current order ownership.
The source revision, reviewed manifest and installed receipt are separate identities;
staging alone does not mean the UI is available on the LAN.

Primary text/button contrast calculations are 6.11:1 in light mode and 9.24:1
in dark mode. Live/stale badge labels use theme-appropriate semantic colors rather
than low-contrast fixed light colors. Selected chart controls use a faint green tint.
